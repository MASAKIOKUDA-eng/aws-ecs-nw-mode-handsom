# DevOps Agent 評価シート

## 採点基準

| 項目 | 基準 |
|------|------|
| 原因（R） | 2：根本原因まで正しい / 1：方向は合っている / 0：誤り・特定できず |
| 粒度（G） | T：タスク / I：インスタンス / S：サービス / N：特定できず |
| 根拠（E） | 使ったデータの略号：FL＝Flow Logs、CI＝Container Insights、EV＝ECS イベント、AL＝ALB メトリクス、LG＝アプリログ、CT＝CloudTrail、他 |
| 時間（T） | 調査開始から根本原因が示されるまで（分） |
| 追加質問（Q） | 回数 |
| 稼働（S） | エージェント稼働時間（秒）。AWS/AIDevOps 名前空間のメトリクスから |
| 対処案（M） | 2：そのまま使える / 1：一部修正が必要 / 0：不適切・なし |
